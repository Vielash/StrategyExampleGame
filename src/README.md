# Mage Battle Game

This is a turn-based battle game where two mages fight using spells and status effects.

## Features
- Two players (mages) take turns attacking each other.
- Various spells and effects (e.g., damage, freezing, healing) are used in the game.
- The game continues until one of the players' health points reach zero.

## How to Play
1. Clone the repository.
2. Open the project in your preferred Java IDE (IntelliJ IDEA recommended).
3. Run the `Main` class to start the game.

## Requirements
- Java 11 or higher.
